How it's built

Deck
Vite + React + TypeScript web app. Every slide is a 1920×1080 canvas scaled to the screen. GSAP drives all motion, one timeline per slide cut into click beats. Presenter view, overview and keyboard/clicker control are custom.
Brand
Zulu tokens from the master deck: Oswald Light, Schibsted Grotesk, JetBrains Mono (Google Fonts), charcoal and paper, signal green for the machine.
Images
Codex CLI on your ChatGPT plan (default from now on). Fal (nano-banana) was used for the first 81 images.
Audio
ElevenLabs: sound effects, music, voice clean-up, and live transcription for the dictation slide.
Live demo
Claude API (Opus 5.5) turns the dictated ramble into a structured brief. It needs the Anthropic key; it works offline with a prepared brief.
3D
Spark, World Labs' open-source 3D (Gaussian splat) renderer, showing two World Labs sample scenes on the step-inside slides.
Media
ffmpeg, bundled with the project, for clip encoding, GIF to MP4 and WebP images.
Built by
Claude Code: me as lead, plus five helper agents working section by section from the shared CLAUDE.md, brand guide and skills.
