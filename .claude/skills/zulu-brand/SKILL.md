# Zulu brand

1. Read `brand/BRAND.md` (mark, colour, type, voice, imagery) and use the CSS variables in `brand/tokens.css`. Never hard-code a brand hex when a token exists.
2. Ground: charcoal `--zak-ink` for machine moments, paper `--zak-paper` for human moments. Colour comes from imagery; UI stays monochrome plus small doses of `--zak-signal` (the machine's colour).
3. Type: Oswald Light caps for display, Schibsted Grotesk 500 sentence case for statements, JetBrains Mono caps for labels and anything the machine "says".
4. Geometry: pills and dots from the ZAK mark (`ZAK_PARTS` in `projects/ai-trends/src/components/ZakMark.tsx`). Debossed slots (`--zak-deboss-dark`) for wells.
5. Voice: plain, specific, short. No hype, no exclamation marks. Keep approved copy word for word.
6. Generated imagery: photographic, tactile, editorial, natural light, film grain. Ban the generic AI look (purple gradients, holograms, robots, brains, glossy skin). Add "no text, no logos" to prompts.

Before you call something finished, check: does it look like Zulu (restraint, confidence, one idea), or like a template?
